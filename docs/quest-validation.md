# 실제 Quest 검증표

개발 환경에서 확인한 버전은 Unity 6000.4.0f1, Meta XR Core·MRUK 209.0.0, OpenXR 1.16.1, Unity Input System 1.19.0, Python 3.12.9, .NET SDK 9.0.100입니다. 프로젝트에 커밋이 아직 없어서 이번 변경을 Git SHA로 특정할 수 없습니다. `python3 scripts/relay.py doctor`에서 연결 환경의 버전과 기능을 다시 확인할 수 있습니다.

작업 중 읽기 전용 `adb devices -l`은 연결 기기 목록이 비어 있었습니다. 이 표의 실제 Quest 항목은 모두 `not_run`입니다. 실제 STT와 사진 비교는 이 작업 환경에 키와 모델 설정이 없어 `not_run`입니다.

| 항목 | 상태 | 현장에서 남길 증거 |
| --- | --- | --- |
| 업데이트 APK 설치와 실행 | `not_run` | 설치 및 실행 로그와 기기 모델 |
| 권한 승인 후 실제 RGB 사진 저장 | `not_run` | JPG, 프레임 시각, 출처, 크기, SHA-256 |
| 헤드셋 마이크 10초 음성 입력·재생 | `not_run` | 동의된 WAV와 재생한 단계·시각 |
| 승인된 키트 및 실물 보드 프로필 일치 | `not_run` | 전원 차단, 치수와 레일 연속성 확인 |
| 다섯 실물 기준점 정렬 | `not_run` | 중심·모서리 오차, 실패·재시도 횟수 |
| 실물 ArUco 마커 프레임과 정합 확인 | `not_run` | 인쇄 눈금, 이미지 출처, 두 독립 검증점 오차 |
| 교수 보드에서 별도 학생 배치로 전이 | `not_run` | 교수·학생 등록 ID와 두 위치의 보드 표시 |
| 머리 이동·보드 옮김·재등록 | `not_run` | 고정·숨김·재표시 영상과 등록 버전 |
| PC 요청과 기기 촬영의 중복 방지 | `not_run` | 동일 요청 ID의 사진 수와 촬영 상태, 부품 집기 시 요청 여부 |
| 실제 서비스 전사와 선택적 사진 비교 | `not_run` | 제공자·모델·품질·지연, 승인 전 검토 기록 |
| 오프라인과 앱 재실행 복구 | `not_run` | 저장한 승인 버전, 단계 유지, 새 보드 정합 요청 |
| 권한 거부·프레임 없음·무음 | `not_run` | 원인과 재시도 상태 표시 |
| 학습자 배선 확인과 LED 점등 관찰 | `not_run` | 확인자·시각·범위가 남은 실습 결과 |
| 렌더링·온도·전력 | `not_run` | 장비 refresh rate, frame timing, 필요한 경우 실제 계측 |
| 이벤트·주기 처리량 비교 | `not_run` | 별도 동의한 밀집 벤치마크와 원본 타임스탬프 |
| 학습자 파일럿 | `not_run` | 관찰자 기록과 사용성 시도. 동일 가이드의 2D/XR 조건과 AB/BA 순서 |

자동 테스트, 데스크톱, 시뮬레이터와 APK 결과는 `artifacts`의 이번 실행 보고서 및 로그로 확인합니다. 설정값을 확인한 API 목록은 실제 센서 통과의 증거로 사용하지 않습니다. 연구용 통계는 밀집 기록·참가자·독립 판단이 있을 때만 집계합니다.
