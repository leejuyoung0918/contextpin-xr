# 케이블 정리대 XR 시연

보내준 `cable_organizer.scad`를 로컬에 등록하면, 두 단계의 후보를 실제 OpenSCAD 형상으로 미리 준비합니다. 대본의 발화와 선택 이유는 예시 기록으로 표시됩니다.

## 실행

```sh
python3 scripts/prepare_cable_demo.py /path/to/cable_organizer.scad
python3 scripts/relay.py replay-server
```

별도 위치의 OpenSCAD는 `OPENSCAD_EXECUTABLE`로 지정합니다. 준비 스크립트는 원본 바이트를 로컬 `artifacts/cable-demo/`에 보관합니다. [OpenSCAD·Unity 설치](openscad-assembly.md)

[PC 회의 화면](http://127.0.0.1:8788/meeting/) · [인쇄용 QR 정렬 카드](../backend/meeting/web/assembly-qr-card.svg)

## 시연 순서

1. Quest에서 **대본으로 체험 → QR로 자동 정렬**을 누릅니다. 고정 받침의 카드를 바라보고 반투명 V1 위치를 확인한 뒤 **실물 일치 확인 → 예시 회의 시작**을 누릅니다. 상태에 **예시 진행**이 표시됩니다. 패널은 **잡고 옮기기**를 트리거로 누른 채 끌 수 있습니다.
2. 가까운 책상을 바라보고 패널에 **Quest에서 찾은 책상**이 뜨는지 확인합니다. 등록된 방이 없으면 **공간 설정**을 열어 스캔할 수 있습니다. 상판을 직접 지정하려면 **책상 지정**을 누르고 오른쪽 컨트롤러의 표시점을 빈 상판의 앞왼쪽, 앞오른쪽, 뒤오른쪽에 차례로 맞춰 **A**를 누릅니다. V1의 홈 쪽을 가리켜 트리거를 누르거나 **1차 · 홈 수정안 보기**를 누릅니다. 비교 화면이 열리면 실물 위 V1 옆에 A·B·C가 실물 크기로 뜹니다. A는 홈 입구만, B는 홈 내부만, C는 둘 다 줄입니다. **A → 이 안 채택**으로 V2를 저장합니다.
3. 가상 V2 위를 가리키고 트리거를 누르거나 **2차 · 길이 수정안 보기**를 누릅니다. A 66mm, B 60mm, C 54mm를 비교합니다. V2의 홈 입구와 내부 치수, 홈 개수 5개가 유지됩니다. **B → 이 안 채택**으로 V3를 저장합니다.
4. **설계 이력 보기**에서 V1·V2·V3를 골라 버전 모델과 변경 이유를 확인합니다.
5. **예시 진행 · 회의 종료 → PC에서 회의록 받기**를 누릅니다. 10분 안에 PC의 8788 시연 서버 시작 화면 **회의록 받기**에 표시된 10자리 코드를 입력해 대본 전사와 설계 결정이 담긴 TXT를 받습니다. 전체 파일은 PC 결과 화면 또는 Quest **메뉴 → 결과 ZIP 저장**에서 받습니다. ZIP에는 실행 가능한 최종 SCAD, 최종 STL, `design_history.json`, 이전 채택 모델과 대본 전사가 들어 있습니다.

현장에서 하는 대화를 실제로 기록할 때는 Quest 첫 화면의 **새 회의 만들기 → 녹음 시작**을 사용합니다. 로컬 음성 모델·등록 치수 플래너 실행 방법과 음성으로 후보를 요청하는 순서는 [실시간 설계 회의](live-collaboration.md)에 있습니다.

첨부 원본의 전체 길이는 84mm입니다. A의 홈 입구는 목 폭 4.2→3.4mm, 상단 폭 6.0→5.2mm로 줄이고 내부 직경 5.6mm를 유지합니다. 2차 후보는 5홈과 끝 여백을 고정하고 홈 피치를 조정합니다.

## QR 설치

진행자 PC 화면의 **참가 QR**은 회의 입장용입니다. Quest에서 새 회의를 직접 만든 경우에는 입장 절차를 건너뜁니다. 실물 위치를 맞출 때는 고정 받침의 **정렬 QR**을 사용합니다. [인쇄용 정렬 카드](../backend/meeting/web/assembly-qr-card.svg)

카드를 100% 배율로 인쇄합니다. 검은 정사각형은 80mm, QR 중심에서 오른쪽의 CAD 원점까지는 90mm입니다. 이전 카드를 가진 경우 중심에서 원점까지 90mm인 기존 카드도 사용 가능합니다. 카드의 흰 여백을 유지하고 방향 표시대로 받침에 고정합니다. 실제 받침의 위치·회전 차이는 로컬 `assembly.json`의 `qr_alignment.mounting`에 넣습니다.

공간 데이터 접근을 허용하고 QR 네 모서리가 보이게 가까운 거리에서 정면으로 바라봅니다. 추적 준비, QR 내용 판독, 위치 확인 상태가 순서대로 표시됩니다. 실물에 반투명 원본이 제대로 겹치면 **실물 일치 확인**을 누릅니다. 받침을 옮겼으면 다시 정렬합니다. 카드나 추적기를 사용할 수 없을 때는 수동 정렬을 선택합니다. [Meta Quest QR 추적 문서](https://developers.meta.com/vr/documentation/unity/unity-mr-utility-kit-qrcode-detection/)

## 반복 확인

```sh
MEETING_EDGE_URL=http://127.0.0.1:8788 python3 tests/meeting/cable_demo_smoke.py
```

검증 결과와 데모 ZIP은 `artifacts/cable-demo/`에 생성됩니다. 실제 케이블의 삽입·이탈 저항과 맞음새는 출력한 시제품에서 확인합니다.
